Dream

Every great product starts with a frustration. Here's the one that started this.

🥗 Log meals & calories
📏 Monitor body measurements
📈 See visual progress over time
🆓 100% free — no subscription ever
STEP 2

Theory

Why does this product need to exist? Three reasons.

01

People want control over their data

Popular apps like MyFitnessPal hide features behind paywalls. Users deserve full access to their own health data without a monthly fee.

02

All-in-one reduces friction

Switching between 3–4 apps for workouts, nutrition, and body stats creates drop-off. One unified dashboard keeps habits consistent.

03

Visible progress drives motivation

People who regularly review their progress are significantly more likely to maintain healthy habits long-term. Visibility is the engine.

STEP 4

Tool

Six technologies. Zero dollars. Fully public.

🌐

GitHub Pages

Free static hosting — the site is public and accessible to anyone with the link, from any device.

💾

localStorage

Browser-based storage keeps all user data (workouts, meals, body stats) on-device — no backend needed.

🍎

Open Food Facts API

CORS-compatible food search API for the nutrition tracker. Free, open-source, and massive database.

🤖

Claude AI (Anthropic)

Used to generate, debug, and iterate all HTML/CSS/JS pages rapidly throughout the development process.

✏️

GitHub Web Editor

All edits made directly in the GitHub browser editor — pencil icon → select all → paste → commit.

📦

Vanilla HTML/CSS/JS

No frameworks — pure web standards. Works on any device without build tools or dependencies.
